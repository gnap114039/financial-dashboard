退休進度與預估退休年齡**全程以「實質（今日購買力）」為基準**，量同一個目標 `targetReal`（退休目標，今日購買力，預設 3000 萬）。`inflatedTarget = targetReal × (1+通膨)^年數` 只作顯示（「退休目標（通膨換算後）」），不參與進度/年齡計算。

## 公式

**實質報酬率（Fisher，相除不是相減）：**
```
實質報酬 = (1 + 預估年化報酬率) / (1 + 通膨) − 1
例：(1.06)/(1.032) − 1 = 2.71%   （直接相減 6%−3.2%=2.8% 略高，程式用相除版）
月實質報酬 i = (1 + 實質報酬)^(1/12) − 1
```

**進度（實質基準）：** `進度% = 目前總資產 / targetReal`（不再用 inflatedTarget；消除「進度低卻顯示可提早退休」的 frame 矛盾）。

**預估退休年齡（年金閉式解 monthsToTarget）：** 求最小月數 m 使
```
FV(m) = current·(1+i)^m + pmt·((1+i)^m − 1)/i ≥ targetReal
解得 g = (target + pmt/i) / (current + pmt/i)，m = ln(g) / ln(1+i)，向上取整
邊界：current≥target→0；|i|≈0→(target−current)/pmt；g≤0→無法達標(Infinity)；m>600→「50 年內無法達標」
```
（取代原本 1..600 逐月迴圈；1080 組參數 brute-force 與舊迴圈結果一致，退休年齡不變。）

## 實質 ≡ 名目 等價性（為何用今日目標能反推到通膨後金額）

恆等式：`實質資產(m) = 名目資產(m) / (1+通膨)^(m/12)`，故
```
實質資產(m) ≥ targetReal（今日）
  ⟺ 名目資產(m) ≥ targetReal × (1+通膨)^(m/12)   ← 第 m 月通膨調整後實際所需金額
```
→ 兩邊**同一個月**達標。用較低的實質報酬成長到「今日目標」，等價於用名目報酬成長到「那個時點通膨後的目標」。所需時間相同。

- 對**現有總資產（一筆錢滾）**：等價**無條件成立**。
- 對**每月投入**：僅當「投入維持今日購買力」（名目金額逐年隨通膨調高）才完全等價。程式假設每月實質投入固定（如 8 萬）。若實際永遠只投固定名目金額（不隨通膨加），程式會**略微樂觀**，實際達標稍晚。

**Why:** 使用者多次確認此模型；理解「實質報酬 + 今日目標」與「名目報酬 + 通膨後目標」等價，才能正確解讀進度與退休年齡。

**How to apply:** 改退休相關計算時保持實質基準一致；勿把 inflatedTarget 用回進度/年齡。相關會計見 [[total-return-accounting]]、[[cost-basis-convention]]。
